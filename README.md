# MULLET FORCE asset pack

Game assets for the Playground build. Served through jsDelivr:

    https://cdn.jsdelivr.net/gh/oneminutegamerllc-svg/MULLET-FORCE@main/<path>

`manifest.json` lists every sheet with frame sizes, frame names, fps and parallax
values. The game loads the manifest first and resolves every file against `base`.

All art generated with OpenArt (Nano Banana 2) and processed (magenta key,
divider removal, baseline alignment) by Claude. Owner: Scott Wisniewski.
